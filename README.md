# 2026 컴퓨터활용능력 1급 필기 연습

컴퓨터활용능력 1급 필기시험을 회차별·과목별로 연습할 수 있는 정적 웹사이트입니다.

## 제공 기능

- 실전 모의고사 5회분, 회차당 60문제
- 컴퓨터 일반·스프레드시트 일반·데이터베이스 일반 과목별 집중 풀이
- OX 반복 문제은행 100문제
- 오답 복습과 3회 연속 정답 졸업 처리
- `/seojang/` 경로의 정답 및 해설 보기
- 브라우저에 진행 상황 자동 저장

## 로컬 실행

별도 설치 없이 프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python3 -m http.server 8766
```

브라우저에서 `http://127.0.0.1:8766/`을 열면 됩니다.

## 주요 경로

- `/` — 실전 모의고사
- `/ox/` — OX 문제은행
- `/seojang/` — 정답 및 해설

## 구성

- `exam-data.js` — 실전 모의고사 문제 데이터
- `ox-data.js` — OX 문제은행 데이터
- `assets/questions/` — 표·그림 확인이 필요한 문제 이미지
